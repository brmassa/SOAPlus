## Overview
SOAPlus Core provides the foundation for implementing the ScriptableObject Architecture Pattern in Unity projects.

## Features
- Base classes for events, variables, and references
- Type-safe event system
- Flexible variable management
- Editor integration

## Installation
```bash
openupm add com.brunomassa.soapluscore
```

## Components
- `BaseEvent<T>`: Foundation for type-safe events
- `BaseVariable<T>`: Variable storage with change detection
- `BaseReference<T,TVariable>`: Flexible reference system
- `BaseListener<T>`: MonoBehaviour event listeners
