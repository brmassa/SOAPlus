## Overview
SOAPlus Builtin provides ready-to-use implementations of common types using the SOAPlus Core framework.

## Features
- Common Unity type implementations
- Ready-to-use components
- Editor integration

## Installation
```bash
openupm add com.brunomassa.soaplusbuiltin
```

## Components
- Primitive types (Int, Float, String)
- Unity types (Vector2, Vector3)
- Common listeners and events
